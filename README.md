# Payal Kar Dutta - Personal Portfolio Website

A premium, elegant portfolio website for Payal Kar Dutta, Founder & CEO of Veva Realty and V Spaces. This static website showcases professional expertise, ventures, achievements, and insights in the real estate industry.

## 🌟 Features

- **Responsive Design**: Fully responsive layout optimized for desktop, tablet, and mobile devices
- **Modern UI/UX**: Elegant dark theme with gold accents (#C8A46B) and smooth animations
- **Single Page Application**: Smooth scrolling navigation with anchor links
- **Interactive Elements**: 
  - Mobile navigation drawer with backdrop blur
  - Animated statistics counter
  - Timeline with hover effects
  - Swiper.js carousel for insights
- **Performance Optimized**: Pure static HTML/CSS/JS with no build process required
- **SEO Friendly**: Meta tags and semantic HTML structure

## 🚀 Getting Started

### Prerequisites
- A web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, for development)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/abhi963007/payal-updated.git
```

2. Navigate to the project directory:
```bash
cd payal-updated
```

3. Open `index.html` in your web browser

### Development

For development with live reload, you can use any static web server:

**Using Python:**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**Using Node.js (http-server):**
```bash
npx http-server -p 8000
```

**Using VS Code Live Server:**
- Install the "Live Server" extension
- Right-click on `index.html` and select "Open with Live Server"

Then open `http://localhost:8000` in your browser.

## 🎨 Customization

### Colors
The primary color scheme uses:
- **Background**: `#05070a` (dark)
- **Accent**: `#C8A46B` (gold)
- **Text**: `#ffffff` (white) and `#94a3b8` (slate)

Modify these in `css/style.css` to customize the color scheme.

### Content
- Edit `index.html` to change text content, sections, and structure
- Replace images in the `images/` directory with your own assets
- Update contact information and social links

### Fonts
The project uses Google Fonts:
- **Cormorant Garamond**: Serif font for headings
- **Outfit**: Sans-serif font for body text
- **Pinyon Script**: Signature font for decorative elements
